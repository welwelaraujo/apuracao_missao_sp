# Instruções para o Claude

- Nunca adicione o Claude como autor ou coautor de commits. Não inclua linhas `Co-Authored-By: Claude ...` nem qualquer outra menção ao Claude ou à Anthropic em mensagens de commit.
- Nunca adicione rodapés como "Generated with Claude Code" em descrições de pull request.
- Os commits deste repositório têm como autor apenas Wellington Araujo.
